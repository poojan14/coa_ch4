# COA Chapter 4

Interactive teaching site for Computer Organization & Architecture, Chapter 4: addressing modes, data transfer and arithmetic, logic and masks, shifts, program control, status bits, conditional branches, RISC vs CISC, hardwired vs microprogrammed control, and a working microprogram (sequencer) simulator, ending with an exit quiz.

Each page gives a short theory first, then a "Try it" demonstration. Everything is in one file, `index.html`; there is no build step and no server code.

Live site: https://poojan14.github.io/coa_ch4/
